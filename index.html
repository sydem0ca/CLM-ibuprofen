Ибупрофен

Ибупрофен — нестероидный противовоспалительный препарат (НПВС)
Блокирует ферменты COX-1 и COX-2, уменьшая синтез простагландинов
В результате снижается: боль воспаление температура
  • Преимущества
  • Быстро всасывается при приёме внутрь
  • Начало действия: 15–30 минут
  • Длительность эффекта: 6–8 часов
  • Преимущества
  • Снимает боль без необходимости применения опиоидов
  • Подходит для кратковременного лечения болевых синдромов
  • разные формы выпуска для удобства (таблетки, суспензия, гель)
